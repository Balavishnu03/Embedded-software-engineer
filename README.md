Projects

1. Smart Vehicle Monitoring System

Description:
A C-based simulation project that monitors vehicle parameters and identifies abnormal conditions using threshold-based checks.

Features:

- Engine temperature monitoring
- Battery voltage monitoring
- Engine RPM monitoring
- Fuel level monitoring
- Vehicle data validation
- Fault detection and diagnostic messages
- Warning messages for abnormal conditions

Technologies Used:

- C Programming
- GCC Compiler
- Visual Studio Code
- GitHub

Project Structure:

Smart-vechicle-monitoring/
├── main.c
├── vehicle_monitor.h
├── vehicle monitoring.c
├── diagnostics.c
├── diagnostics.h
└── README.md

How to Compile and Run:

Compile the source files using GCC:

gcc main.c "vehicle monitoring.c" diagnostics.c -o vehicle_monitor.exe

Run the program on Windows PowerShell:

.\vehicle_monitor.exe

Learning Outcomes:

- Learned to organize code using header and source files.
- Implemented conditional statements and functions.
- Practiced input validation and threshold-based fault detection.
- Learned to compile and execute a multi-file C program.

Note: This is a simulation-based learning project. It does not directly connect to real vehicle sensors or hardware.
